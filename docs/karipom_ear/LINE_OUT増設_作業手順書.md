# LINE OUT増設 作業手順書

**v1.0** ／ Karipom Ear ／ 2026-07-26
対象構成：**既存PCM1808 ＋ 既存Pico 2 H ＋ CoreS3**（Bluetoothは今回対象外）

---

## 0. この手順書の範囲

**やること**

1. 手持ちの3.5mmジャック配線に、**470Ωの抵抗を2本挿入**する
2. それを **CN3** へ接続し、**LINE OUT** として機能させる
3. 改造の前後で **PCM1808への入力レベルが変わっていないこと**を実測で確認する
4. アクティブスピーカーを繋いで**音が出ること・ハムが出ないこと**を確認する

**完成後の使い方**

```
音源（Mac / スマホ）
   └→ 3.5mmケーブル → 既設ジャック（PCM1808基板上）→ PCM1808 → Pico 2 → CoreS3（口パク・グライコ）
                          │
                          └（基板内部で並列）→ CN3 →[470Ω]→ LINE OUTジャック → アクティブスピーカー
```

**音源は今までどおり既設ジャックに挿します。CN3はLINE OUT専用になります。**

**やらないこと**

- Bluetooth（MH-M18）関連の作業一切
- 入力切替回路、分圧回路
- PCM1808基板・CoreS3の改造
- 筐体（Fusion 360）側のジャック取り付け穴の設計 ※必要になったら別途

**所要時間の目安：60〜90分**（はんだ付けを含む）

**環境**

- [ ] はんだ付けができる場所（換気できる・こて台がある）
- [ ] 絶縁台（段ボールまたはプラ板）がある
- [ ] 時間に余裕がある

- [ ] 熱収縮チューブ（φ2mm 4本分以上。**φ4mm以上があればなお良い**）

## 3. やってはいけないこと

### 🔴 絶対禁止

| やってはいけないこと | 起きること |
|---|---|
| **通電したままCN3の配線を抜き差しする** | ショート・破損 |
| **LINE OUTジャックにイヤホン／ヘッドホンを挿す** | 470Ωで大きく減衰し、ほとんど聞こえません。ライン入力専用です |
| **Pico 2の既存配線（GP0〜GP4、VSYS、GND）を抜く** | 動作中のKaripom Earが壊れます |
| **熱収縮チューブを通す前にはんだ付けする** | やり直しになります（M2で経験済み） |
| **音源をCN3へ挿す** | CN3はLINE OUT専用です。音源は既設ジャックへ |

### 🟡 避けること

- 作業の途中でMacの音量を変える（**改造前後の比較ができなくなります**）
- 抵抗を入れた部分を繰り返し曲げる（断線しやすい箇所です）
- 判断に迷ったまま次の工程へ進む（**迷ったら止まる**）

## 4. 完成する回路

```
                    ┌─[ 470Ω ]─── 青（L）
CN3 L_IN ───────────┘

                    ┌─[ 470Ω ]─── 赤（R）
CN3 R_IN ───────────┘

CN3 GND ──────────────────────── 黒（GND）
                                    │
                            3.5mmジャック
                                    │
                          アクティブスピーカーへ
```

**黒（GND）には抵抗を入れません。** 入れるのは青と赤の2本だけです。

# 作業手順

> 各工程に **⚡通電あり** / **🔌無通電** / **💻PC作業** を明記しています。

---

## 工程1　測定用ファームを書き込む　💻PC作業

**何をするか**
改造前後のレベルを数値で比較するため、Pico 2に測定用スケッチを入れます。

**どうするか**

1. Arduino IDEで `Karipom_Ear_MEAS_InputLevel` フォルダ内の `Karipom_Ear_Pico_MEAS_InputLevel.ino` を開く
2. ボード設定が Raspberry Pi Pico 2 になっていることを確認
3. Pico 2へ書き込む
4. シリアルモニタを **115200bps** で開く

**正常なら**
起動バナー `Karipom Ear v2 - M3a 入力レベル校正 測定スケッチ v1.0` が表示され、1秒ごとに `MEAS>` 行が出る。

**異常なら**
書き込みに失敗する → Pico 2の **BOOTSELボタンを押しながらUSBを挿し直す**（マスストレージとして認識させる）方法で復旧できます。

> **CoreS3の口パク・グライコはこの間停止します。正常です。** 工程10で元に戻します。

---

## 工程2　改造前の基準レベルを測る　⚡通電あり

> ⚠️ **この工程を飛ばすと、改造後に「レベルが下がったかどうか」を判断できなくなります。必ず実施してください。**

**何をするか**
LINE OUTを付ける前の入力レベルを記録します。

**どこに挿すか**

1. **音源（Mac）→ 3.5mmオス–オスケーブル → 既設ジャック（PCM1808基板上）**
2. **CN3には何も挿さない**

**どうするか**

3. 400Hzサイン波WAVを再生する
4. Macの音量を上げていき、`peakL` が **44〜50%** のあたりで止める
5. **以降、作業が全部終わるまでMacの音量には触らない**
6. 値が安定したら、記録表の「A：改造前」に `peakL` と `peakR` を記入する

**正常なら**
`clip=0/0`、`mis=0`、`ovf=0` で、peakLが安定して読める。

**異常なら**
`MEAS>` 行が出ない／peakが0% → 音源が既設ジャックに正しく挿さっているか確認。M3aと同じ状態です。

---

## 工程3　無通電にする　⚡→🔌

**どうするか**

1. Macの再生を停止する（**音量は触らない**）
2. **Pico 2のUSBケーブルを抜く**
3. **CoreS3のUSBケーブルを抜く**
4. CoreS3の画面が完全に消えていることを目視で確認する
5. 音源のケーブルを既設ジャックから抜く

**正常なら**
すべての電源が切れている。

**異常なら**
画面が消えない → 他にも電源が繋がっています。すべて切ってから進んでください。

---

## 工程4　抵抗を配線に挿入する　🔌無通電（はんだ付け）

**何をするか**
青（L）と赤（R）の線の途中に、470Ωを1本ずつ入れます。

### 4-1　青（L）の線に入れる

1. 470Ωを1本取り、**両側のリード線をニッパーで約5mmに切り詰める**
2. 青い線の**中央あたり**をニッパーで切断する
3. 切断した両側の被覆を、それぞれ **約5mm** 剥く
4. **熱収縮チューブを先に線へ通す**（φ2mmを2本、切断部の左右に1本ずつ）
   > 🔴 **ここを飛ばすと、はんだ付け後には通せません。**
5. 片側の芯線を抵抗のリードに巻き付け、はんだ付けする
6. もう片側も同様に、抵抗の反対側のリードにはんだ付けする
7. 熱収縮チューブを**それぞれのはんだ部分にかぶせて**加熱・収縮させる
   > 抵抗の本体（色帯のある部分）は絶縁塗装されているので、露出したままで構いません。**φ4mm以上のチューブがあれば、抵抗ごと1本で覆うとより確実です。**
8. 軽く引っ張って、抜けないことを確認する

### 4-2　赤（R）の線に入れる

9. 4-1と同じ手順を、赤い線でもう1本の470Ωについて行う

### 4-3　黒（GND）

10. **黒い線には何もしません。そのままです。**

**正常なら**
青と赤の途中に抵抗が1本ずつ入り、はんだ部分が熱収縮チューブで覆われている。

**異常なら**

| 症状 | 対処 |
|---|---|
| はんだが芋状で光沢がない | 加熱不足。もう一度こてを当て直す |
| 引っ張ると抜ける | 接続不良。やり直す |
| チューブを通し忘れた | チューブをカッターで縦に切って外し、新しいものを通してやり直す。**ためらわず作り直してください** |

---

## 工程5　抵抗値とショートの確認　🔌無通電

> ⚠️ **CN3に挿す前に必ず確認します。** M2と同じ考え方です。

**準備**

1. 3.5mmオス–オスケーブルの片端を、製作したジャックに挿す
2. **反対側のプラグはどこにも繋がず、自由にしておく**
3. 3本のメスコネクタに、余りのピンヘッダを1本ずつ挿す（プローブを当てやすくするため）
4. テスターのダイヤルを **2kΩ（または470Ωが測れる範囲）** に合わせる

### 5-A　抵抗が正しく入っているか

| 測る場所 | 期待する値 |
|---|---|
| 自由端プラグの**チップ（先端）** ↔ **青**のコネクタ | **約 440〜500Ω** |
| 自由端プラグの**リング（中間）** ↔ **赤**のコネクタ | **約 440〜500Ω** |
| 自由端プラグの**スリーブ（根元）** ↔ **黒**のコネクタ | **ほぼ 0Ω**（1Ω以下） |

記録表に実測値を記入してください。

**判定**

- 3つとも期待どおり → **5-Bへ**
- 🔴 **青または赤が「0Ω付近」** → 抵抗が入っていない、または抵抗をまたいでショートしている → 工程4をやり直す
- 🔴 **青または赤が「1」「OL」で振り切れる** → 断線している → 工程4をやり直す
- 🔴 **黒が0Ωにならない** → GND線の接続不良 → 確認する

### 5-B　ショートしていないか

テスターを **200kΩ以上（またはオート）** に切り替えます。

| 測る場所 | 期待する結果 |
|---|---|
| 青 ↔ 赤 | 「1」または「OL」 |
| 青 ↔ 黒 | 「1」または「OL」 |
| 赤 ↔ 黒 | 「1」または「OL」 |

> **プローブの金属部を指で握らないでください。** 人体の抵抗が表示され、誤判定します。

**判定**

- 3つとも「1／OL」 → **工程6へ**
- 🔴 0Ω付近が出た → どこかでショートしています。工程4をやり直す

## 工程6　CN3へ接続する　🔌無通電

**何をするか**
製作した配線をCN3へ挿します。

**どうするか**

1. **すべてのUSBが抜けていること**を再確認する
2. 自由端に挿したピンヘッダを抜く
3. PCM1808基板のCN3のシルク文字（`L_IN` / `GND` / `R_IN`）を読む
4. **黒（GND）→ `GND`** に挿す
5. **青（L）→ `L_IN`** に挿す
6. **赤（R）→ `R_IN`** に挿す
7. 目視確認：1本ずつ正しいピンに乗っているか／2本のピンにまたがっていないか／根元まで真っ直ぐか
8. 抵抗部分が他の部品や基板に押し付けられていないことを確認する

**正常なら**
3本が正しいピンに挿さり、抵抗部分に無理な力がかかっていない。

**異常なら**
シルクが読めない → M2のときと同じ配置です。**推測せず、写真を撮ってClaudeへ**。

> **M2との違いに注意**：M2ではCN3が「入力」でしたが、今回は「出力」です。**配線の挿し方は同じ**ですが、音源はCN3ではなく**既設ジャック**へ挿します。

---

## 工程7　通電してレベルを再測定（スピーカー未接続）　⚡通電あり

**何をするか**
LINE OUT回路を付けたことで入力レベルが変わっていないかを確認します。

**どうするか**

1. **LINE OUTジャックには何も挿さない**
2. 音源（Mac）→ 3.5mmケーブル → **既設ジャック** に接続
3. Pico 2のUSBをMacに挿す（CoreS3も通常どおり接続してよい）
4. シリアルモニタを開く
5. **工程2と同じ400Hzサイン波を、同じ音量で**再生する（**音量は触っていないはず**）
6. `peakL` `peakR` を記録表の「B：改造後・スピーカー未接続」に記入する

**正常なら**
**工程2（A）とほぼ同じ値**になる。差が **±2%以内**なら影響なしと判断できます。

**異常なら**

| 症状 | 対処 |
|---|---|
| peakが大きく下がった（5%以上） | USBを抜き、工程5・工程6を再確認 |
| peakが0% | USBを抜き、CN3の挿し位置を確認 |
| `mis` が急増した | USBを抜き、既存のI2S配線に触れていないか確認 |

---

## 工程8　アクティブスピーカーを接続して音を出す　⚡通電あり

**何をするか**
LINE OUTが実際に機能するかを確認します。

**どうするか**

1. **アクティブスピーカー／アンプの音量を最小にする**
2. 3.5mmオス–オスケーブルで、**LINE OUTジャック → スピーカーのライン入力**に接続する
3. スピーカーの電源を入れる
4. Macで音楽（サイン波でなく通常の楽曲でよい）を再生する
5. **スピーカーの音量をゆっくり上げていく**

**正常なら**
- スピーカーから音楽が聞こえる
- **同時にCoreS3の口パク・グライコも動いている**（測定用ファーム中は動きません。工程10以降で確認します）

**異常なら**

| 症状 | 対処 |
|---|---|
| 音が出ない | Macの音量、スピーカーの入力切替、ケーブルの挿し込みを確認 |
| 片方のチャンネルしか出ない | 青または赤の接続不良。工程5からやり直す |
| **「ブーン」というハム音が出る** | グラウンドループの可能性。**音量を下げ、記録表に記入して報告**（対処法があります） |
| 音が極端に小さい | LINE OUTにイヤホンを挿していないか確認。**ライン入力専用**です |

---

## 工程9　スピーカー接続時のレベルを測定　⚡通電あり

**何をするか**
スピーカーを繋いだ状態でも入力レベルが落ちないことを確認します。

**どうするか**

1. スピーカーを接続したまま、**工程2と同じ400Hzサイン波を同じ音量で**再生する
2. `peakL` `peakR` を記録表の「C：改造後・スピーカー接続」に記入する

**正常なら**
**A・B・Cの3つがほぼ同じ値**（差が±2%以内）。

**異常なら**
Cだけ大きく下がる → スピーカー側の入力インピーダンスが想定より低い可能性。**値を記録して報告**してください。

---

## 工程10　元のファームへ戻す　💻PC作業

**どうするか**

1. Macの再生を停止する
2. Arduino IDEで **`Karipom_Ear_Pico_Step2_UART_Echo.ino`** を開く
3. そのまま書き込む
4. **復帰確認**
   - シリアルモニタに `Karipom Ear v2 - Step 2 UART Echo v1.0` のバナーが出る
   - `ST> rmsDb=... gate=... fft/s=...` が1秒ごとに出る
   - **CoreS3の口パク・グライコが元どおり動く**

**正常なら**
音楽を再生すると、**スピーカーから音が出ながら、かりポムも口パクする**。これが今回の完成状態です。

**異常なら**
書き込み失敗 → BOOTSELボタンを押しながらUSBを挿し直す

---

## 工程11　片付けと最終確認　⚡→🔌

**どうするか**

1. 再生を停止し、スピーカーの音量を最小にして電源を切る
2. 必要に応じてUSBを抜く
3. **最終確認**

- [ ] Pico 2の既存配線（GP0〜GP4、VSYS(39)、GND(38)）が**すべて元のまま**
- [ ] CN3に3本が正しく挿さっている
- [ ] 抵抗部分に無理な力がかかっていない
- [ ] 既設ジャックに音源が挿さっている
- [ ] LINE OUTジャックがスピーカーへ繋がっている
- [ ] 口パク・グライコが正常に動作する
