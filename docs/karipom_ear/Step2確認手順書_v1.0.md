# Karipom Ear v2 — Step 2 確認手順書（UARTエコー検証・Pico単体）

- **文書番号**：KPE-STEP2-001 ／ 版数 v1.0 ／ 作成日 2026-07-12
- **対象**：Karipom_Ear_Pico_Step2_UART_Echo.ino v1.0
- **前提**：Step 1合格済み（配線・ジャンパ・fs設定は変更しない）。**CoreS3にはまだ接続しない**

## 1. 事前準備

- ☐ Arduino IDEライブラリマネージャで **arduinoFFT（kosme版）v2.x** をインストール（v1系はAPI非互換。バージョン表記が2.0以上であること）
- ☐ 配線はStep 1のまま（DATA→GP2／BCLK→GP3／LRCK→GP4／MCLK未接続）。Groveケーブルは接続しない
- ☐ （任意・推奨）ループバック自己試験：**GP0（物理1番）とGP1（物理2番）をジャンパ1本で直結**。UARTの電気層までPico単体で検証できる。外せば自動的に無効（lb=--）

## 2. 手順

1. スケッチ書き込み→シリアルモニタ（115200bps）
2. 起動バナー→ `[ OK ] ALIGN: attempt=N fmt=X 判定=確定` を確認（**fmtがStep 1の記録と同一であること**）
3. **無音テスト（30秒）**：`TX> FFT:0,0,...` 系と `ST>` 行を観察
4. **音楽テスト（30秒）**：バンド値の変化・`SPEAK_START`・ハートビート・停止後の `SPEAK_STOP` を観察
5. **1kHzトーンテスト**：特定バンドだけ突出することを確認
6. ログを保存し、GATE_OPEN_DB調整が必要ならその値を記録

## 3. 想定シリアル出力例

```
[ OK ] ALIGN: attempt=1 fmt=A 判定=確定
ST> 行: rmsDb gate fft/s n mis ovf lb
ST> rmsDb=-78.2 gate=closed fft/s=25 n=95994 mis=0 ovf=0 lb=OK
TX> FFT:0,0,0,0,0,0,0,0
（↑無音時。TX>行は毎秒25行流れる）

（音楽再生開始）
TX> SPEAK_START
TX> FFT:62,55,41,38,27,19,12,6
TX> SPEAK_START          ← 1秒毎ハートビート
ST> rmsDb=-21.4 gate=OPEN fft/s=25 n=96012 mis=0 ovf=0 lb=OK
（再生停止から約0.5秒後）
TX> SPEAK_STOP
```

## 4. Step 2単体の成功条件（すべて満たすこと）

**A. 基盤の維持（Step 1品質が劣化していないこと）**

- ☐ `ALIGN 判定=確定`・fmtがStep 1と同一
- ☐ `mis=0`・`ovf=0`・`n≈96000` が全テストを通じて維持（FFT処理追加でnが落ちないこと＝処理能力の証明）

**B. プロトコル書式**

- ☐ FFT行が **`FFT:` + 0〜100の整数8個カンマ区切り**（空白なし・末尾改行）で、`ST>`行の `fft/s=25`（±2）
- ☐ `SPEAK_START`/`SPEAK_STOP` が正確にこの文字列（既存CoreS3パーサ互換の生命線）

**C. 挙動**

- ☐ 無音：全バンドほぼ0、gate=closed、SPEAK系が一切出ない（5分間誤発火なし）
- ☐ 音楽：開始後すみやかに `SPEAK_START`、開いている間1秒毎ハートビート、停止後約0.5〜1秒で `SPEAK_STOP` が1回だけ
- ☐ 音楽中、低音の強い曲でband[0..2]が大きく、バンド値が曲に追従して毎行変化
- ☐ **1kHzトーン**：band[4]または[5]（500-1000/1000-2000Hz帯）だけが突出し、隣接以外はほぼ0（バンド割りが正しい証明）
- ☐ 音量2倍→バンド値とrmsDbが明確に増加

**D. UART電気層（ループバック実施時のみ）**

- ☐ GP0-GP1直結で `lb=OK`（＝GP0から実際に電気信号が出ている証明）。ジャンパを外すと `lb=--`

**E. 安定性**

- ☐ 30分連続でリセット・ハング・`[WARN]`連発なし

全項目合格でStep 3（CoreS3側の受信実装・実装仕様書v2.0 §4）へ進む。

## 5. 調整ノブ（合格に必要な場合のみ変更・記録すること）

| 定数 | 既定値 | 用途 |
|---|---|---|
| GATE_OPEN_DB / GATE_CLOSE_DB | -45 / -50 dBFS | 誤発火する→上げる（-40等）。反応しない→下げる（-50/-55等） |
| GATE_HANG_MS | 500ms | 口パクの切れ際の保持時間 |
| FFT_FLOOR_DB / FFT_TOP_DB | -63 / -3 dBFS | バンドが常時0→FLOORを下げる。常時100→TOPを上げる |
| ECHO_EVERY_N | 1 | USBログが流れすぎる場合5に（UART送信自体は25Hzのまま） |

## 6. 設計メモ（レビュー用）

- 送信は全行 `txLine()` 1関数経由：UARTとUSBエコーの内容乖離を構造的に防止
- デシメーションは6点平均（96k→16k）。簡易LPF相当であり、Phase 0の8バンド用途には十分（Phase 1で要すれば真のFIRへ）
- FFTフレームは512点@16kHz=32ms（約31回/秒）、送信は40ms周期（25Hz）で最新値を送る
- ゲートはヒステリシス付き（開-45/閉-50dBFS）＋500msハングオーバ。**VADではない**（Phase 2で置換）
- `Serial1.setTX(0)/setRX(1)` はbegin前に呼ぶ（arduino-picoのピン割当規則）
- ループバックはSerial1 RXを読むだけの受動検出。CoreS3接続時（Step 3以降）はこのRXがコマンド受信に転用される
