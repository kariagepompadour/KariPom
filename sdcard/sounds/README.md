# KariPom 音声ファイルについて

KariPomで使用する音声ファイルは、本リポジトリには含まれていません。
お好みの音声合成ソフトなどを使用してWAVファイルを作成し、
この `sounds` フォルダ内に配置してください。

## 固定音声

以下のファイル名で音声を用意すると、対応する場面で再生されます。

- `wifi_failed_1.wav` — Wi-Fi接続に失敗したとき
- `online_ready.wav` — Wi-Fi接続完了時
- `hungry.wav` — バッテリー残量低下時
- `yawn.wav` — あくび時

## 独り言音声

独り言として使用したいWAVファイルは、

`sounds/mutter/`

フォルダ内に配置してください。

`mutter` 内のWAVファイルはKariPomが読み込み、
独り言機能で使用します。

音声ファイルが存在しない場合でもKariPom本体は動作しますが、
対応する音声再生機能は使用できません。

💡 `sounds/mutter/` が空の場合、互換性維持のため旧形式の独り言ファイル名を探索し、
ログに `WAV OPEN FAIL` が表示される場合がありますが、異常ではありません。
音声ファイルがない場合でもKariPom本体の動作は継続します。

使用する音声合成ソフトや音声素材の利用規約・ライセンスは、
各自で確認してください。
